## 📖 About

A modern, interactive personal portfolio built from scratch — no frameworks, no build tools, just clean HTML, Tailwind, and vanilla JavaScript. It showcases my work as an **IT Engineering student specializing in Machine Learning**, with a focus on:

- 🤖 **Machine Learning** — models, algorithms, and AI-powered products
- 🧠 **Competitive Programming** — algorithms & data structures (Codeforces)
- 🌐 **Full-Stack Web** — JavaScript, PHP, Laravel, MySQL
- 🎨 **Creative Coding** — Canvas animations, generative art, micro-interactions
- 🎮 **3D & Game Dev** — Unity, Blender

> **Flagship project:** [**Stickorator**](https://stickorator.ai.studio) — an AI-powered creative studio that turns ideas into custom stickers and character art, built end-to-end from the ML pipeline to the real-time web interface.

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🎬 | **Cinematic preloader** | Custom "LAITH_HH" wipe-in animation inspired by Lando Norris |
| 🎯 | **Dynamic navbar** | Auto-hides on scroll-down, reveals on scroll-up, with live section tracking |
| 🖼️ | **Interactive hero card** | Hover/tap to reveal a rotating **skills donut gallery** |
| 🔤 | **Typewriter effect** | Cycles through my specialties in real time |
| 🎨 | **Generative canvas** | Type any word → watch it draw itself with animated strokes |
| 💫 | **Interactive form border** | Particles orbit the contact form and react to your mouse |
| 🗂️ | **Filterable projects** | Filter by Full-Stack / Frontend / AI-ML |
| 📱 | **Fully responsive** | Mobile-first design with a dedicated mobile menu + toggle |
| ⚡ | **Zero dependencies** | No build step, no `node_modules` — opens in any browser |
| ♿ | **Accessible** | ARIA labels, keyboard nav, reduced-motion support |

## 🛠️ Tech Stack

**Frontend**
- HTML5 · CSS3 · Vanilla JavaScript (ES2020+)
- [Tailwind CSS](https://tailwindcss.com) (via CDN with custom config)
- [Font Awesome 6](https://fontawesome.com) — icons
- [Google Fonts](https://fonts.google.com) — Inter & Fira Code

**Creative / Interactive**
- HTML5 `<canvas>` API — generative art & particle physics
- Custom CSS keyframe animations
- IntersectionObserver for scroll-reveal effects

**Backend / Services**
- [Formspree](https://formspree.io) — contact form handling
- GitHub Pages — hosting

**Languages I work with**
- Python · C# · C++ · JavaScript · PHP · SQL
