# Growing Image Gallery

An image gallery with hover interactions that smoothly expand and emphasize the selected image.

## Run

Open `index.html` in a modern web browser. The demo uses the local `style.css` and `script.js` files. Shared media is referenced from repository-level asset folders under `../../assets/`.
