# Mini Projects

Standalone HTML, CSS, and JavaScript experiments. Each demo lives in a folder named after its original HTML file and can be opened through its `index.html`.

Project details, display order, and landing-page filter definitions are collected in [`projects.js`](./projects.js). Every project's `image_path` defaults to `assets/icons/app.png`; lower `order` values appear first.
